Token Radar: a dashboard ranking pre-token DefiLlama protocols by implied launch value, with a farm plan for each. It reads the sealed DefiLlama snapshot, scores every protocol on the watchlist plus the strongest pre-token protocols below the floor, and renders a static board with a detail view and filters for every protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
